# Changelog

## English companion package 1.0.0 — 2026-11-11

- Eight preformatted companion files from Appendices A–E, preserved from the supplied English EPUB apart from final-newline normalization.
- Four fill-in worksheets covering the minimum Loop specification, verification/evidence, budgets, and retry/fallback/circuit-breaker decisions.
- English download instructions, provenance mapping, rights boundaries, and reader question/correction forms.
- Explicit separation of source templates, illustrative State, and runtime evidence.

The package version identifies these companion files. It is not a claim that a GitHub release has been published or that any runtime described by the book has been executed. The full book, graphics, production tools, and unavailable companion programs are excluded.
