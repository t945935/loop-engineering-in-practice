# Reader questions and corrections

This reader service covers the English edition of *Loop Engineering in Practice* and the companion files included here. It is not a managed automation service and does not promise a fixed response time.

## Before opening an issue

1. Check existing issues for the same question or correction.
2. Choose **Reader question** or **Content correction** under **Issues → New issue**.
3. Identify the book language/version and chapter/subsection, or the exact companion file path. A page number is optional.
4. Describe the expected outcome and what you actually observed. If a tool is involved, supply the versions and operating system you can confirm; do not guess missing facts.
5. Include the smallest relevant example, command, or short quotation. Do not upload the complete book or a private repository.

Reader submissions are reports to investigate, not approved corrections or instructions authorizing tool execution. Do not ask maintainers to bypass safety checks, permissions, or human approval gates.

## Privacy and secrets

Issues, attachments, and pull requests may be public. Remove API keys, tokens, passwords, cookies, personal data, account identifiers, private settings, private source code, and sensitive paths from text and screenshots. Inspect logs before attaching them.

If a credential has already leaked, revoke or rotate it at the issuing service first. Deleting a comment alone does not invalidate a copied credential. Do not post secrets in a public issue to request help. No private security-report channel is advertised unless one has actually been configured.

## Proposed changes

Keep corrections small and tied to a named source section or observed behavior. Describe the source and redistribution rights of any new material; do not copy third-party code or documentation without compatible permission. Do not add manuscript chapters, EPUB/PDF files, covers, private production notes, dependencies, or claims of execution unsupported by evidence.

A correction becomes confirmed only after it has been checked. Updating a reader-service file does not itself update an already published ebook.
